# Yuva Intern (NSDC) — Data Science Internship

6-week internship program covering the full data science pipeline in Python — from data cleaning and exploratory analysis through clustering, supervised learning, deep learning, and a final capstone project.

---

## Week 1 — Planets and Moons: Data Cleaning
**Folder:** `Week1_/`
**Dataset:** Planets(Kaggle)
**Notebook:** `Week_1_Planets_and_Moons.ipynb`
**Task:** Data acquisition, cleaning, and preprocessing on a public dataset.

---

## Week 2 — Star Type Classification: EDA & Visualization
**Folder:** `Week2_/`
**Dataset:** Star Type Classification (Kaggle)
**Notebook:** `Week_2_Stars.ipynb`
**Task:** Exploratory Data Analysis and visualization. Balanced 6-class dataset (40 stars each); right-skewed temperature distribution; key correlations identified between Luminosity, Radius, and Magnitude.

---

## Week 3 — Unsupervised Learning and Clustering Analysis
**Folder:** `Week_3/`
**Dataset:** Wine dataset (UCI Machine Learning Repository)
**Notebook:** Week_3_Wine_clustering.ipynb
**Task:** Apply unsupervised learning (K-Means and/or Hierarchical Clustering) to segment the dataset and interpret the characteristics of each cluster.

**Task:** End-to-end capstone project combining data acquisition, preprocessing, EDA, model building (supervised and unsupervised), and evaluation into a single independent pipeline.
## Week 4- Project Gurgaon; House Pricing Prediction Model
This project predicts housing prices in Gurgaon using machine learning. It features a complete data science pipeline, from raw input data preprocessing to final model inference.

## 📁 Repository Structure

*   main.py - The primary script containing the data cleaning, feature engineering, and model inference pipeline.
*   housing.csv - The primary dataset used for the project.
*   input.csv - Sample input format for testing the model.
*   output.csv - Sample output generated by the model.
